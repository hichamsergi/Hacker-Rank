# Hacker-Rank

Repositorio dedicado a la resolución de ejercicios y documentación de apuntes técnicos enfocados en Python y sus librerias.

## 📁 Estructura del Repositorio

*   **`Hacker_Rank/`**: Ejercicios y desafíos de lógica y algoritmos de la plataforma HackerRank.

*   **`Pandas_exercises/`**: Prácticas intensivas de manipulación de datos del repositorio [pandas_exercises](https://github.com/guipsamora/pandas_exercises/tree/master):

    *   **`01_Getting&KnowingUrData/`**: Introducción, exploración inicial y carga de datasets.

    *   **`02_Filtering&Sorting/`**: Técnicas de filtrado, indexación y ordenación de DataFrames.

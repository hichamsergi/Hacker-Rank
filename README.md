# Hacker-Rank

Repositorio dedicado a la resolución de ejercicios y documentación de apuntes técnicos enfocados en análisis de datos con Python.

## 📁 Estructura del Repositorio

*   **`Hacker_Rank/`**: Ejercicios y desafíos de lógica y algoritmos de la plataforma HackerRank.

*   **`Pandas_exercise/`**: Prácticas intensivas de manipulación de datos estructuradas por módulos:

    *   **`01_Getting&KnowingUrData/`**: Introducción, exploración inicial y carga de datasets.

    *   **`02_Filtering&Sorting/`**: Técnicas de filtrado, indexación y ordenación de DataFrames.
